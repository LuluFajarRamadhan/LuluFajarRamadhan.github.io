# 🟢 PART 1: Pengenalan Dasar Statistika
---
## 🎯 Tujuan Pembelajaran
Setelah mempelajari bagian ini, diharapkan:
- Memahami apa itu statistika
- Mengetahui perbedaan statistika deskriptif dan inferensial
- Mengenali jenis-jenis data
- Memahami skala pengukuran data

---

## 📊 1. Apa itu Statistika?

**Statistika** adalah ilmu yang mempelajari cara:
- Mengumpulkan data
- Mengolah data
- Menganalisis data
- Menyajikan data
- Menarik kesimpulan dari data

📌 Contoh dalam kehidupan sehari-hari:
- Nilai rata-rata ujian di kelas
- Data penjualan harian sebuah toko
- Hasil survei kepuasan pelanggan

---

## 📈 2. Statistika Deskriptif vs Inferensial

🟡 Statistika Deskriptif

Digunakan untuk:
- Menggambarkan atau mendeskripsikan data

Contoh:
- Rata-rata nilai siswa
- Diagram batang jumlah penduduk

📌 Tidak digunakan untuk membuat prediksi

--
🔵 Statistika Inferensial

Digunakan untuk:
- Menarik kesimpulan dari sampel ke populasi
- Membuat prediksi

Contoh:
- Survei 100 orang untuk mewakili 1 juta penduduk
- Prediksi hasil pemilu

---

## 🌍 3. Peran Statistika dalam Kehidupan

Statistika digunakan dalam berbagai bidang:

- 📚 Pendidikan → analisis nilai siswa
- 💼 Bisnis → analisis penjualan & keuntungan
- 🏥 Kesehatan → penelitian obat
- 📊 Pemerintahan → sensus penduduk
- ⚽ Olahraga → statistik performa pemain

📌 Intinya: statistika membantu pengambilan keputusan berbasis data

---

## 🧩 4. Jenis-Jenis Data

### 🔹 Data Kualitatif
Data berupa kategori atau label (bukan angka)

Contoh:
- Jenis kelamin (L/P)
- Warna favorit
- Status pernikahan

---

### 🔹Data Kuantitatif
Data berupa angka

### 1. Data Diskrit
- Nilainya terhitung (bilangan bulat)

Contoh:
- Jumlah siswa
- Jumlah mobil

---

### 2. Data Kontinu
- Nilainya bisa dalam rentang (pecahan/desimal)

Contoh:
- Tinggi badan (170.5 cm)
- Berat badan (65.2 kg)
- Waktu tempuh

---

## 📏 5. Skala Pengukuran

### 1️⃣ Skala Nominal
- Hanya sebagai label/kategori
- Tidak ada urutan

Contoh:
- Jenis kelamin
- Warna

---

### 2️⃣ Skala Ordinal
- Ada urutan, tapi tidak ada jarak pasti

Contoh:
- Ranking (1, 2, 3)
- Tingkat kepuasan (puas, cukup, tidak puas)

---

### 3️⃣ Skala Interval
- Ada urutan dan jarak
- Tidak memiliki nol mutlak

Contoh:
- Suhu (°C, °F)

📌 0°C bukan berarti tidak ada suhu

---

### 4️⃣ Skala Rasio
- Ada urutan, jarak, dan nol mutlak

Contoh:
- Berat badan
- Tinggi badan
- Umur

📌 0 berarti benar-benar tidak ada

---

# 🧠 Ringkasan

- Statistika = ilmu pengolahan data
- Deskriptif = menjelaskan data
- Inferensial = membuat kesimpulan/prediksi
- Data:
  - Kualitatif (kategori)
  - Kuantitatif (angka → diskrit & kontinu)
- Skala:
  - Nominal → label
  - Ordinal → urutan
  - Interval → jarak tanpa nol mutlak
  - Rasio → lengkap (ada nol mutlak)
