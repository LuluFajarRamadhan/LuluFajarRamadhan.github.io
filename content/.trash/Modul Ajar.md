# Tujuan Pembelajaran

Melalui eksplorasi grafik fungsi sinus menggunakan GeoGebra, peserta didik mampu:

1. Menemukan hubungan antara perubahan nilai parameter dengan amplitudo grafik sinus.
2. Menemukan hubungan antara perubahan nilai parameter dengan periode grafik sinus.
3. Menentukan amplitudo dan periode grafik sinus dengan benar.

---

# Langkah Pembelajaran

## A. Pendahuluan (±2 Menit)

### Salam

Guru memberi salam dan menyiapkan suasana belajar.

### Motivasi

Guru menampilkan Slide 1.

Terdapat satu grafik dasar

\[
y=\sin x
\]

Guru bertanya

> "Menurut kalian, jika saya hanya mengubah SATU angka pada persamaan ini, apakah bentuk grafiknya akan berubah?"

Guru memberikan kesempatan peserta didik memberikan prediksi.

Guru menyampaikan tujuan pembelajaran.

> "Hari ini kita tidak akan menghafal rumus. Kita akan membuktikan sendiri bagaimana sebuah angka dapat mengubah bentuk grafik fungsi sinus."

---

# B. Kegiatan Inti (±11 Menit)

## Sintaks Discovery Learning

### 1. Stimulation

Guru membuka GeoGebra.

Menampilkan

\[
y=A\sin x
\]

dengan

```
A = 1
```

Guru bertanya.

> "Menurut kalian, apa yang akan berubah jika slider ini saya geser?"

Peserta didik memberikan prediksi.

---

### 2. Problem Statement

Guru menggeser slider

```
A = 2

A = 3

A = 0,5
```

Guru mengajukan pertanyaan.

- Apa yang berubah?
- Apa yang tetap?
- Apakah jumlah gelombangnya berubah?
- Mengapa grafik menjadi lebih tinggi?

Guru belum memberikan jawaban.

---

### 3. Data Collection

Peserta didik mengamati.

Guru mengajak mengisi tabel.

| Nilai A | Tinggi Grafik |
|----------|---------------|
| 1 | |
| 2 | |
| 3 | |
| 0,5 | |

---

### 4. Data Processing

Guru bertanya.

> "Jadi, parameter A memengaruhi apa?"

Peserta didik menyimpulkan.

Guru memberikan penguatan.

> "Besarnya simpangan maksimum terhadap garis tengah disebut amplitudo."

---

### 5. Verification

Guru mengganti persamaan menjadi

\[
y=\sin(Bx)
\]

dengan

```
B = 1
```

Guru menggeser slider

```
B = 2

B = 3

B = 0,5
```

Guru bertanya.

- Apa yang berubah?
- Apakah tinggi grafik berubah?
- Mengapa grafik semakin rapat?
- Mengapa grafik semakin renggang?

Peserta didik mengemukakan hasil pengamatan.

Guru memberikan penguatan.

> "Panjang satu gelombang penuh disebut periode."

Guru menunjukkan bahwa

- semakin besar B → periode semakin kecil.
- semakin kecil B → periode semakin besar.

---

### 6. Generalization

Guru menampilkan tiga grafik.

- Sinus
- Cosinus
- Tangen

Guru bertanya.

> "Menurut kalian, fungsi mana yang memiliki amplitudo?"

Peserta didik menjawab.

Guru bertanya kembali.

> "Mengapa grafik tangen tidak memiliki amplitudo?"

Guru mengajak peserta didik melengkapi tabel.

| Fungsi | Amplitudo | Periode |
|---------|-----------|----------|
| Sinus | | |
| Cosinus | | |
| Tangen | | |

Guru memberikan penguatan.

| Fungsi | Amplitudo | Periode |
|---------|-----------|----------|
| Sinus | 1 | \(2\pi\) |
| Cosinus | 1 | \(2\pi\) |
| Tangen | Tidak memiliki amplitudo | \(\pi\) |

---

# C. Penutup (±2 Menit)

Guru memberikan pertanyaan refleksi.

> "Jika saya ingin grafik menjadi dua kali lebih tinggi, parameter mana yang harus saya ubah?"

> "Jika saya ingin grafik menjadi dua kali lebih rapat, parameter mana yang harus saya ubah?"

Guru bersama peserta didik menyimpulkan.

> "Perubahan parameter pada fungsi sinus memengaruhi amplitudo dan periode grafik."

Guru menutup pembelajaran.

Observasi dan tanya jawab.
